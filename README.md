# GenzDream

## About the Project
GenzDream is a web-based counseling system designed to help students submit their queries and connect with an admin or counselor for support.

## Features
- **Student Counseling Form:** Students can submit their name, email, and queries.
- **Success Notification:** Confirmation after successful form submission.
- **Admin Login:** Secure login for the administrator.
- **Admin Dashboard:** View and manage student counseling requests.
- **Data Management:** Store and retrieve student requests from the database.

## Project Modules
1. **Student Module**
   - Submit counseling forms.
   - Receive submission confirmation.

2. **Admin Module**
   - Verify login credentials.
   - Access the dashboard.
   - View student queries and requests.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL

## Installation and Setup
1. Install a local server such as XAMPP.
2. Clone or download this repository.
3. Place the project folder inside the `htdocs` directory.
4. Start Apache and MySQL from XAMPP.
5. Import the project database into phpMyAdmin.
6. Configure the database connection in the project files.
7. Open the project in your browser using:

   `http://localhost/GenzDream/`

## Project Purpose
The purpose of GenzDream is to make student counseling requests easier to submit and manage through a simple web-based platform.
